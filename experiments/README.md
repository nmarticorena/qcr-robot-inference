# Experiments

Folder for storing experiments configs to allow for replicating each configuration

## Franka evals

the local folder `franka_evaluation` contains evaluation configs for the single panda set up. These experiments are generated by `scripts/evaluation/franka/create_evaluation.py`, where each experiment follow the following folder structure: 
```
.
└── experiment_name/
    ├── experiment_000/
    │   ├── side.png
    │   ├── wrist.png
    │   └── ...
    ├── experiment_001/
    ├── ...
    ├── experiment_nnn/
    └── experiments.json
```
each `experiment_id` contains a home/starting position and an image to get the locations of the target objects.
